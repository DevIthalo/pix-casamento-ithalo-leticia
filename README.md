# Presente de Casamento - Ithalo & Letícia 💍

Uma página de presentes de casamento elegante, minimalista e funcional, desenvolvida com HTML5, CSS3 e JavaScript puro. Projetada para ser leve, rápida e fácil de usar.

## ✨ Funcionalidades

- **Design Editorial**: Interface sofisticada inspirada em publicações de luxo.
- **Totalmente Responsivo**: Experiência otimizada para celulares e computadores.
- **Opções de Presente**:
  - **Valor Sugerido**: Link direto para contribuição via Nubank.
  - **Valor Livre**: Opção para o convidado definir o valor do presente.
- **Cópia de Chave Pix**: Funcionalidade de "copiar e colar" simplificada com feedback visual.
- **Animações Fluidas**: Transições suaves de entrada e interações dinâmicas nos botões.

## 🚀 Como Visualizar

Este projeto não requer instalação de dependências ou servidores. 

1. Faça o download ou clone os arquivos.
2. Localize o arquivo **`index.html`**.
3. Abra-o com o seu navegador de preferência (Chrome, Safari, Edge, etc.).

## 📂 Estrutura de Arquivos

- `index.html`: Estrutura principal da página.
- `style.css`: Estilização completa, incluindo fontes e animações.
- `script.js`: Lógica de interação e efeitos dinâmicos.
- `public/`: Contém as imagens de fundo e logo do casal.

## 🛠️ Tecnologias

- HTML5 Semântico
- CSS3 (Flexbox, Grid, Animações)
- Vanilla JavaScript
- Google Fonts (Inter & Noto Serif)
- Material Symbols (Ícones)
